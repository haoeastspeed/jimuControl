# 极目 JimuControl

**个人远程控制软件** —— 用手机或平板远程控制你的 Windows 电脑，端到端加密，免费公开、自由使用，无需账号。

- 产品官网：<https://haoeastspeed.github.io/jimuControl/>
- 下载地址：<https://github.com/haoeastspeed/jimuControl/releases>

## 简介

极目由两部分组成：

- **Windows 电脑端（被控端）**：运行在需要被远程控制的电脑上，采集屏幕与声音并接收远程操作。
- **Android 主控端**：安装在手机或平板上，显示远程画面并进行键鼠、触屏、文件等操作。

两端使用相同的访问密钥即可连接。远程内容在你的设备之间端到端加密，不经过任何第三方服务器。

## 特性

- 高清画面与实时音频，H.264 硬件编解码，弱网自适应码率 / 帧率
- ChaCha20-Poly1305 端到端加密，访问密钥仅保存在你的设备之间
- 虚拟鼠标高精度指针、完整键盘（含 F1–F12、系统输入法中文）、触屏操作
- 剪贴板文字 / 图片 / 文件双向同步
- 远程文件浏览、上传下载、重命名复制，支持断点续传与远程搜索
- 隐私模式：电脑黑屏、隐藏光标、本地不可操作
- Wake-on-LAN 远程唤醒、会话录制、断线自动重连、多主机历史
- 局域网直连 + ZeroTier 跨网段组网，任意网络下均可连接
- 内置自动更新：App / 程序内一键检查并升级

## 快速上手

1. 在 Windows 电脑下载并运行极目，软件默认自动启动服务。
2. 在 Android 手机安装极目 APK 并打开，自动扫描或手动填写电脑 IP。
3. 两端输入一致的访问密钥（至少 6 位），点击连接即可。

跨网络使用时，请在两端开启 ZeroTier 并加入同一个网络；同一局域网内无需 ZeroTier。

## 连接方式

| 方式 | 适用场景 | 说明 |
| --- | --- | --- |
| 局域网直连 | 手机与电脑在同一 Wi-Fi / 路由器 | 自动 UDP 发现、一键连接，延迟最低 |
| ZeroTier 跨网段 | 不同网络、手机使用流量 | 免费点对点虚拟组网，安装包已内置、可一键安装 |

默认端口：TCP `49160`（连接）、UDP `49161`（局域网发现），首次运行会自动放行防火墙。

## 自动更新

极目两端均内置自动更新，更新清单为仓库根目录的 [`update.json`](update.json)，同时通过 GitHub Pages 提供固定访问地址：

```
https://haoeastspeed.github.io/jimuControl/update.json
```

程序启动后会自动检查新版本，也可在界面内手动检查。安卓安装包提供 SHA-256 校验，防止下载损坏或被篡改。

## 安全说明

- 远程画面、音频与操作指令均为端到端加密，访问密钥从不上传。
- ZeroTier 仅用于点对点组网与连接建立，无法读取加密后的内容。
- 隐私模式下电脑本地屏幕黑屏，适合在公共环境使用。
